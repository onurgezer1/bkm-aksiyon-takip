== Description ==

BKM Aksiyon Takip is a comprehensive WordPress plugin designed for businesses and organizations to efficiently track actions, manage tasks, and monitor team performance. Built with Turkish businesses in mind, it offers a complete solution for project management and workflow optimization.

= Key Features =

* **Action Management**: Create, track, and manage actions with detailed information
* **Task Assignment**: Assign tasks to team members with due dates and priorities
* **Category Organization**: Organize actions and tasks by custom categories
* **Performance Tracking**: Monitor individual and team performance metrics
* **Advanced Reporting**: Generate detailed reports on actions, tasks, and performance
* **User Role Management**: Comprehensive role-based access control
* **Email Notifications**: Automated email notifications for task assignments and updates
* **Progress Tracking**: Visual progress indicators with real-time updates
* **Notes and Comments**: Add notes and comments to actions and tasks
* **Responsive Design**: Mobile-friendly interface for on-the-go management
* **Turkish Language Support**: Full Turkish localization included

== Installation ==

= Automatic Installation =

1. Log in to your WordPress admin dashboard
2. Navigate to Plugins → Add New
3. Search for "BKM Aksiyon Takip"
4. Click "Install Now" and then "Activate"

= Manual Installation =

1. Download the plugin zip file
2. Log in to your WordPress admin dashboard
3. Navigate to Plugins → Add New → Upload Plugin
4. Choose the downloaded zip file and click "Install Now"
5. Click "Activate Plugin"

= After Installation =

1. Navigate to "BKM Aksiyon Takip" in your admin menu
2. Configure categories and performance metrics
3. Set up user roles and permissions
4. Configure email notification settings
5. Start creating actions and assigning tasks

== Frequently Asked Questions ==

= Can I use this plugin in English? =

Yes, while the plugin is designed for Turkish businesses, it includes proper internationalization support. You can translate it to any language using standard WordPress translation tools.

= Does this plugin work with multisite? =

Yes, BKM Aksiyon Takip is compatible with WordPress multisite installations.

= Can I customize the fields and categories? =

Yes, the plugin includes a flexible category management system, and performance metrics can be customized to fit your organization's needs.

= Is there a user manual or documentation? =

Yes, comprehensive documentation is included with the plugin, and additional support resources are available.

= Can I export reports? =

Yes, the reporting system includes export functionality for generating external reports.

= What user roles are supported? =

The plugin integrates with WordPress user roles and adds custom capabilities for action management, task assignment, and reporting access.
